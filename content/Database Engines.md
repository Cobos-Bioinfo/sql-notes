## What is a Database Engine

A **database engine** or (**management system**) is the **software** responsible for storing, organizing and allowing access to data.
- When you write an SQL query, it is the engine that interprets, optimizes and executes it

## SQLite - The Most Used Database in the World

[[SQLite]] is the most used database in the world. Every Android phone, iPhone, web browser, macOS and Windows system includes it.

Because SQLite is **embedded**. No server is needed, the database is a **single file** (**`.db`**) that the application **reads** and **writes** directly from/to.
