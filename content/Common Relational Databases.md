Some of the most common RDs are **MySQL, PostgreSQL, SQLite** and **Miscrosoft SQL Server**.
### Free and Open-Source
- [[MySQL]] is an free and open-source RD management system. 
- [[PostgreSQL]] free, open source object-relational database system. You can define your own data types, custom functions, and write code in different programming languages without re-compiling your database
- [[SQLite]] free, open-source, and light-weight file-based RD engine. Self-contained and **server-less.** Zero-configuration database (does not require initial setup process)

### Propietary
- [[Miscrosoft SQL Server]] Developed by Microsoft
- [[Oracle Database]] scalable RD management system used for enterprise applications that require high performance.
